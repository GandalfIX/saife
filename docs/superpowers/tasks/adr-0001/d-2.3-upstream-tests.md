### S-81: NO_PROXY bypass — direct dial when host matches no-proxy (automated)

**What:** When `HTTPS_PROXY` is set to a non-existent proxy but the target host is in `network.noProxy`, the request succeeds via direct dial (NO_PROXY bypass with Happy Eyeballs). [G-11, G-49]

```powershell
# S-81: NO_PROXY bypass — host in noProxy list dials direct despite HTTPS_PROXY.
function Invoke-Scenario-S81 {
    $d = New-ScenarioDir 81

    # Write a profile that sets upstreamProxy to a non-existent proxy and
    # noProxy to api.anthropic.com, so the target bypasses the broken proxy.
    $profileDir = Join-Path $d 'profiles'
    New-Item -ItemType Directory -Path $profileDir -Force | Out-Null
    $profileJson = '{"meta":{"name":"no-proxy-bypass","schema_version":1},"network":{"allow_domain":["api.anthropic.com"],"upstream_proxy":"http://127.0.0.1:1","no_proxy":["api.anthropic.com"]}}'
    Set-Content -LiteralPath (Join-Path $profileDir 'bypass.json') -Value $profileJson -Encoding UTF8

    $r = Invoke-Sandbox -Args @(
        'run','--profile',(Join-Path $profileDir 'bypass.json'),
        '--allow-cwd','--no-prompt',
        '--','cmd','/c','curl','-s','-o','NUL','-w','%{http_code}',
        'https://api.anthropic.com'
    ) -WorkingDirectory $d
    $out = ($r.Stdout -join '')
    # A 4xx from Anthropic means the connection reached the host (proxy 403
    # would be a 3-digit 403 from our proxy, but NO_PROXY bypass should not
    # hit the 502 upstream-error path). Accept 200 or 4xx (auth rejected).
    $passed = ($out -match '200') -or ($out -match '4[0-9][0-9]')
    return @{ Num=81; Name='S-81 (NO_PROXY bypass)'; Passed=$passed; Skipped=$false
        Detail = if ($passed) { "NO_PROXY bypass: direct dial succeeded (http=$out)" } else { "exit=$($r.ExitCode) stdout=$out stderr=$(($r.Stderr -join '`n'))" } }
}
```

**Setup:** A profile JSON with `upstream_proxy: "http://127.0.0.1:1"` (non-existent) and `no_proxy: ["api.anthropic.com"]`. `--allow-domain api.anthropic.com --no-prompt`.
**Command:** `curl https://api.anthropic.com` inside the sandbox.
**Expected:** Connection succeeds (HTTP 200 or 4xx from Anthropic — the request bypassed the broken upstream proxy and dialed direct with Happy Eyeballs). NOT a 502.
**Audit:** `source: "allowlist"` (the host is in the allow-list; the NO_PROXY bypass is a dial-path concern, not a filter decision).

### S-82: upstream unreachable — 502 Bad Gateway + X-Sandbox: upstream-error (automated)

**What:** When the upstream proxy is non-existent and the target host is NOT in `noProxy`, the proxy returns `502 Bad Gateway` with an `X-Sandbox: upstream-error` header. The body names the upstream proxy (host:port only, no credentials). [G-30, G-49]

```powershell
# S-82: upstream unreachable → 502 + X-Sandbox: upstream-error.
function Invoke-Scenario-S82 {
    $d = New-ScenarioDir 82

    # Profile with a non-existent upstream proxy, no noProxy for the target.
    $profileDir = Join-Path $d 'profiles'
    New-Item -ItemType Directory -Path $profileDir -Force | Out-Null
    $profileJson = '{"meta":{"name":"upstream-dead","schema_version":1},"network":{"allow_domain":["api.anthropic.com"],"upstream_proxy":"http://127.0.0.1:1"}}'
    Set-Content -LiteralPath (Join-Path $profileDir 'dead.json') -Value $profileJson -Encoding UTF8

    # Use curl -v to capture response headers (X-Sandbox: upstream-error).
    $r = Invoke-Sandbox -Args @(
        'run','--profile',(Join-Path $profileDir 'dead.json'),
        '--allow-cwd','--no-prompt',
        '--','cmd','/c','curl','-s','-D','-','-o','NUL',
        'https://api.anthropic.com'
    ) -WorkingDirectory $d -Diag
    $out = ($r.Stdout -join "`n") + ($r.Stderr -join "`n")
    $has502 = $out -match '502'
    $hasHeader = $out -match '(?i)X-Sandbox:\s*upstream-error'
    $passed = $has502 -and $hasHeader
    return @{ Num=82; Name='S-82 (upstream unreachable 502)'; Passed=$passed; Skipped=$false
        Detail = if ($passed) { '502 + X-Sandbox: upstream-error returned' } else { "has502=$has502 hasHeader=$hasHeader exit=$($r.ExitCode) out=$out" } }
}
```

**Setup:** A profile with `upstream_proxy: "http://127.0.0.1:1"` (port 1 = connection refused), no `no_proxy` entry for `api.anthropic.com`. `--allow-domain api.anthropic.com --no-prompt`.
**Command:** `curl -s -D - -o NUL https://api.anthropic.com` (capture headers).
**Expected:** HTTP `502 Bad Gateway` with `X-Sandbox: upstream-error` header. Body contains the redacted proxy address (`127.0.0.1:1`), no credentials.
**Audit:** `source: "upstream-error"`, `disposition: "deny"`.

### S-83: host env detection — no warning alone, SANDBOX_DIAG warning when both set and differ (automated)

**What:** When only the host env `HTTPS_PROXY` is set (no profile `upstreamProxy`), the proxy is detected silently — no warning. When both profile `upstreamProxy` and host env `HTTPS_PROXY` are set AND differ, a `SANDBOX_DIAG` warning is emitted. [G-10, G-42]

```powershell
# S-83: host env detection + SANDBOX_DIAG override warning.
function Invoke-Scenario-S83 {
    $d = New-ScenarioDir 83

    # Part A: only host env HTTPS_PROXY set, no profile upstreamProxy.
    # Expect: no SANDBOX_DIAG warning about override.
    $env:HTTPS_PROXY = 'http://127.0.0.1:9999'
    $rA = Invoke-Sandbox -Args @(
        'run','--allow-cwd','--allow-domain','api.anthropic.com','--no-prompt',
        '--','cmd','/c','echo','env-only'
    ) -WorkingDirectory $d -Diag
    $errA = ($rA.Stderr -join "`n")
    $noWarnA = -not ($errA -match '(?i)SANDBOX_DIAG.*upstreamProxy.*differs')
    Remove-Item env:HTTPS_PROXY -ErrorAction SilentlyContinue

    # Part B: both profile upstreamProxy and host env HTTPS_PROXY set and differ.
    $profileDir = Join-Path $d 'profiles'
    New-Item -ItemType Directory -Path $profileDir -Force | Out-Null
    $profileJson = '{"meta":{"name":"both-differ","schema_version":1},"network":{"allow_domain":["api.anthropic.com"],"upstream_proxy":"http://127.0.0.1:8080"}}'
    Set-Content -LiteralPath (Join-Path $profileDir 'differ.json') -Value $profileJson -Encoding UTF8

    $env:HTTPS_PROXY = 'http://127.0.0.1:9999'
    $rB = Invoke-Sandbox -Args @(
        'run','--profile',(Join-Path $profileDir 'differ.json'),
        '--allow-cwd','--no-prompt',
        '--','cmd','/c','echo','both-differ'
    ) -WorkingDirectory $d -Diag
    $errB = ($rB.Stderr -join "`n")
    $hasWarnB = $errB -match '(?i)SANDBOX_DIAG.*differs'
    Remove-Item env:HTTPS_PROXY -ErrorAction SilentlyContinue

    $passed = $noWarnA -and $hasWarnB
    return @{ Num=83; Name='S-83 (host env detection + override warning)'; Passed=$passed; Skipped=$false
        Detail = if ($passed) { 'env-only: no warning; both-differ: SANDBOX_DIAG warning' } else { "noWarnA=$noWarnA hasWarnB=$hasWarnB errA=$errA errB=$errB" } }
}
```

**Setup — Part A:** Set host env `HTTPS_PROXY=http://127.0.0.1:9999`, run with a profile that has NO `upstreamProxy` field.
**Expected A:** No `SANDBOX_DIAG` override warning on stderr. (The proxy is detected from the host env silently — this is the expected path for corporate dev machines.)
**Setup — Part B:** Set host env `HTTPS_PROXY=http://127.0.0.1:9999`, run with a profile that has `upstream_proxy: "http://127.0.0.1:8080"` (differs).
**Expected B:** `SANDBOX_DIAG` warning on stderr mentioning that the profile `upstreamProxy` differs from the host `HTTPS_PROXY`/`HTTP_PROXY` and that the profile value is used. [G-42]

**Cleanup:** Remove `HTTPS_PROXY` from the environment in both parts (the `Remove-Item env:HTTPS_PROXY` calls) so subsequent scenarios are not affected.
