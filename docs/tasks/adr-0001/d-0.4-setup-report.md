# Task: D-0.4 — Update `setup --check-only` network row with intranet-leak warning

> **ADR:** ADR-0001 §D-0 [G-21, G-34, G-53]
> **Phase:** 1 (keystone)
> **Depends on:** D-0.1 (capability SID must be in place)
> **Blocks:** Checkpoint 1

## Objective

Update the `sandbox setup --check-only` report to accurately reflect the new unprivileged network posture: the `privateNetworkClientServer` capability grants loopback + intranet (not public internet), with an explicit warning about the intranet leak. No admin/setup step is needed for network — the capability SID is a runtime token attribute.

## Current state

`src/setup.rs` line 63:
```rust
println!("Reverse proxy (network)    : available (US-3)");
```

This is misleading — it implies the proxy works, but before D-0 it doesn't (admin-only loopback exemption). After D-0, it works unprivileged but with the documented intranet-leak limitation.

## Implementation

### Step 1: Update the network row in `src/setup.rs`

Replace line 63 with:

```rust
println!(
    "Network (loopback+intranet) : {}",
    if build >= MIN_BUILD {
        "available via privateNetworkClientServer capability (unprivileged)"
    } else {
        "MISSING (requires Windows 10 1709+)"
    }
);
println!(
    "  ⚠ Intranet leak          : raw-socket apps can reach LAN hosts without proxy filtering."
);
println!(
    "    Strong isolation        : use --block-net (zero network capability SIDs, all connect() denied)"
);
```

**Note:** the `⚠` character renders in most Windows terminals (Windows Terminal, PowerShell 7). If there's a concern about legacy `cmd.exe`, use `[!]"` or `"WARNING:"` instead. Check the existing codebase for Unicode usage in println — if none, use ASCII:

```rust
println!(
    "  WARNING (intranet leak)  : raw-socket apps can reach LAN hosts without proxy filtering."
);
```
