## Objective

Add the `sandbox learned` CLI subcommand with three actions: `list`, `revoke <host>`, and `clear`. This gives the user a discoverable way to manage permanent prompt decisions without editing the JSON file directly.

## Current state

`src/cli.rs` `Cmd` enum (lines 16–100) has `Run`, `Ps`, `Audit`, `Profile`, `Setup` — no `Learned` variant. The `LearnedStore` (from D-3.3) has `entries()`, `revoke()`, and `clear()` methods ready to be called.

`src/main.rs` dispatches on `Cmd` — there is no `Cmd::Learned` arm yet.

### Step 4: Implement `list`, `revoke`, `clear`

These are thin wrappers around `LearnedStore`. The simplest approach: add free functions in `src/net/learned.rs` (or a new `src/cmd/learned.rs`):

```rust
//! `sandbox learned list|revoke|clear` command implementations (ADR-0001 §D-3 [G-51]).

use crate::net::learned::LearnedStore;

/// `sandbox learned list` — prints a table of host/scope/disposition.
pub fn list(profile: Option<&str>) -> i32 {
    let store = match LearnedStore::load(profile) {
        Ok(s) => s,
        Err(e) => {
            eprintln!("[sandbox] learned list: {e:#}");
            return 1;
        }
    };
    let entries = store.entries();
    if entries.is_empty() {
        println!("(no learned decisions)");
        return 0;
    }
    // Table header.
    println!("{:<40} {:<8} {}", "HOST", "SCOPE", "DISPOSITION");
    println!("{}", "-".repeat(60));
    for (host, scope, allow) in &entries {
        let disposition = if *allow { "allow" } else { "deny" };
        println!("{:<40} {:<8} {}", host, scope, disposition);
    }
    0
}

/// `sandbox learned revoke <host>` — removes the entry, atomically rewrites.
pub fn revoke(host: &str, profile: Option<&str>) -> i32 {
    let mut store = match LearnedStore::load(profile) {
        Ok(s) => s,
        Err(e) => {
            eprintln!("[sandbox] learned revoke: {e:#}");
            return 1;
        }
    };
    match store.revoke(host) {
        Ok(true) => {
            println!("Revoked learned decision for {host}");
            0
        }
        Ok(false) => {
            eprintln!("[sandbox] no learned decision found for {host}");
            1
        }
        Err(e) => {
            eprintln!("[sandbox] learned revoke: {e:#}");
            1
        }
    }
}

/// `sandbox learned clear` — empties the learned file.
pub fn clear(profile: Option<&str>) -> i32 {
    let mut store = match LearnedStore::load(profile) {
        Ok(s) => s,
        Err(e) => {
            eprintln!("[sandbox] learned clear: {e:#}");
            return 1;
        }
    };
    if let Err(e) = store.clear() {
        eprintln!("[sandbox] learned clear: {e:#}");
        return 1;
    }
    println!("Cleared all learned decisions");
    0
}
```

#[cfg(test)]
mod tests {
    use super::*;
    use clap::Parser;

    #[test]
    fn learned_list_parses() {
        let cli = Cli::parse_from(["sandbox", "learned", "list"]);
        match cli.cmd {
            Cmd::Learned { subcommand, profile } => {
                assert!(matches!(subcommand, LearnedAction::List));
                assert!(profile.is_none());
            }
            _ => panic!("expected Learned"),
        }
    }

    #[test]
    fn learned_list_with_profile_parses() {
        let cli = Cli::parse_from(["sandbox", "learned", "list", "--profile", "developer"]);
        match cli.cmd {
            Cmd::Learned { subcommand, profile } => {
                assert!(matches!(subcommand, LearnedAction::List));
                assert_eq!(profile.as_deref(), Some("developer"));
            }
            _ => panic!("expected Learned"),
        }
    }

    #[test]
    fn learned_revoke_parses() {
        let cli = Cli::parse_from(["sandbox", "learned", "revoke", "api.example.com"]);
        match cli.cmd {
            Cmd::Learned { subcommand, .. } => {
                match subcommand {
                    LearnedAction::Revoke { host } => assert_eq!(host, "api.example.com"),
                    _ => panic!("expected Revoke"),
                }
            }
            _ => panic!("expected Learned"),
        }
    }

    #[test]
    fn learned_revoke_with_profile_parses() {
        let cli = Cli::parse_from([
            "sandbox", "learned", "revoke", "api.example.com", "--profile", "dev",
        ]);
        match cli.cmd {
            Cmd::Learned { subcommand, profile } => {
                assert!(matches!(subcommand, LearnedAction::Revoke { .. }));
                assert_eq!(profile.as_deref(), Some("dev"));
            }
            _ => panic!("expected Learned"),
        }
    }

    #[test]
    fn learned_clear_parses() {
        let cli = Cli::parse_from(["sandbox", "learned", "clear"]);
        match cli.cmd {
            Cmd::Learned { subcommand, .. } => {
                assert!(matches!(subcommand, LearnedAction::Clear));
            }
            _ => panic!("expected Learned"),
        }
    }

    #[test]
    fn learned_revoke_requires_host() {
        // `revoke` without a host argument should fail to parse.
        let result = Cli::try_parse_from(["sandbox", "learned", "revoke"]);
        assert!(result.is_err());
    }
}
