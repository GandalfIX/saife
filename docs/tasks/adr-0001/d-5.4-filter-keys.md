# Task: D-5.4 — Update audit filter keys

> **ADR:** ADR-0001 §D-5 [G-9]
> **Phase:** 2 (audit)
> **Depends on:** D-5.1 (the `source`/`scope`/`persisted` fields must exist first)
> **Blocks:** Checkpoint 2

## Objective

Add `source`, `scope`, and `persisted` to the audit filter's known keys, so users can filter audit output with expressions like `source=hard-deny`, `persisted=true`, or `scope=suffix`.

## Current state

`src/audit/filter.rs` line 34:
```rust
const KNOWN_KEYS: &[&str] = &["op", "disposition", "host", "path", "ts", "pid", "seq"];
```

The filter grammar supports `=` (exact), `~=` (substring), `>=`/`<=` (comparison). Adding new keys makes them filterable.

### Step 2: Handle `persisted` as a boolean filter

The `persisted` field is a JSON boolean (`true`/`false`). The filter's `=` operator does string comparison. Add a normalization so `persisted=true` matches JSON `true` and `persisted=false` matches JSON `false`. This may already work if the filter converts both sides to strings — check the `Clause::matches` implementation.

If the filter compares the raw JSON value as a string, `persisted=true` would match `"persisted":true` in the JSON. Verify this works; if not, add a special case for boolean fields.

### Step 3: Handle `scope` as nullable

The `scope` field is `null` when not applicable (e.g. `source: "allowlist"` decisions don't have a scope). The filter should handle `scope=null` (match null values) and `scope!=null` (match non-null). If the current filter doesn't support `null` comparison, add it:

```rust
// In Clause::matches, handle null comparison:
if value == "null" {
    return event_value.is_null();
}
```

mod tests {

    #[test]
    fn filter_by_source() {
        let f = Filter::parse("source=hard-deny").unwrap();

            r#"{"source":"hard-deny","host":"169.254.169.254"}"#

        assert!(f.matches(&event));
    }

    fn filter_by_source_excludes_others() {
        let f = Filter::parse("source=allowlist").unwrap();

            r#"{"source":"hard-deny","host":"169.254.169.254"}"#
        ).unwrap();
        assert!(!f.matches(&event));
    }
