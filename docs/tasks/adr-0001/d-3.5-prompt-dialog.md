The dialog shows `host:port` and, if an intent is on file (from D-3.4), appends `Agent reason: "<reason>"`.

### Step 3: Define `PromptConfig`, `PromptPolicy`, `PromptResult`

```rust
//! Interactive network prompt dialog (ADR-0001 §D-3).
//!
//! `TaskDialogIndirect` with 6 custom buttons, focus-stealing, fire-and-
//! forget toast. Coalesced by hostname, semaphore-capped at 8 concurrent
//! dialogs. Timed-out dialogs stay on screen (accepted quirk, [G-4]).

use std::collections::HashMap;
use std::net::IpAddr;
use std::sync::Arc;
use std::time::Duration;

use tokio::sync::{Mutex, Semaphore, oneshot};

/// Configuration for the prompt layer, derived from `NetworkConfig::Allow`
/// (after D-3.1).
#[derive(Debug, Clone)]
pub struct PromptConfig {
    pub timeout: Duration,
    pub on_unavailable: PromptPolicy,
}

/// What to do when the dialog backend is unavailable or the prompt times
/// out ([G-48]).
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum PromptPolicy {
    Deny,
    Allow,
}

impl PromptPolicy {
    pub fn from_str(s: &str) -> Self {
        match s.to_ascii_lowercase().as_str() {
            "allow" => PromptPolicy::Allow,
            _ => PromptPolicy::Deny,
        }
    }
}

/// The result of a prompt interaction. `scope` is `"host"` or `"suffix"`;
/// `suffix` is `Some(suffix_hint)` when the user chose a suffix-scoped
/// permanent decision.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum PromptResult {
    Allow { persist: bool, scope: String },
    Deny { persist: bool, scope: String },
    /// The user clicked "Explain more" — the proxy returns 403 with an
    /// `X-Sandbox-Intent-Hint` header so the agent knows to re-declare.
    NeedsIntent,
}
```

### Step 4: Implement `compute_suffix_hint` + `is_loopback_host`

```rust
/// Compute the suffix hint: the host with the leftmost label removed when
/// ≥3 labels, else the host itself. IP literals return the host itself
/// (never generalized). [G-43]
pub fn compute_suffix_hint(host: &str) -> String {
    let h = host.trim_end_matches('.');
    // IP literal → no suffix generalization.
    if h.parse::<IpAddr>().is_ok() {
        return h.to_string();
    }
    let labels: Vec<&str> = h.split('.').collect();
    if labels.len() >= 3 {
        labels[1..].join(".")
    } else {
        h.to_string()
    }
}

/// Is `host` a loopback address? `localhost`, `*.localhost`, `127.0.0.1`,
/// `::1`, and any IP that parses as loopback. Used by the proxy to refuse
/// CONNECT to loopback ([G-44]).
pub fn is_loopback_host(host: &str) -> bool {
    let h = host.trim_end_matches('.').to_ascii_lowercase();
    if h == "localhost" {
        return true;
    }
    if h.ends_with(".localhost") {
        return true;
    }
    if let Ok(ip) = h.parse::<IpAddr>() {
        return ip.is_loopback();
    }
    false
}
```

**[G-43]** Suffix hint is in the button label itself (e.g. "Allow permanently (*.npmjs.org)") so the user sees exactly what the permanent decision covers. `compute_suffix_hint("registry.npmjs.org")` → `"npmjs.org"`; `compute_suffix_hint("api.example.com")` → `"example.com"`; `compute_suffix_hint("example.com")` → `"example.com"` (2 labels, unchanged); `compute_suffix_hint("8.8.8.8")` → `"8.8.8.8"` (IP, unchanged).

### Step 5: Implement `show_dialog` via `TaskDialogIndirect`

```rust
/// Show the prompt dialog. Calls `TaskDialogIndirect` with 6 custom buttons.
/// Steals focus (no `TDF_NO_FOCUS`). Fires a fire-and-forget toast on a
/// separate thread. [G-2, G-3, G-17, G-37]
///
/// This is a blocking call — must be run via `tokio::task::spawn_blocking`
/// (the async caller wraps it, see [`PromptCoordinator::prompt`]).
fn show_dialog(host: &str, port: u16, reason: Option<&str>, suffix_hint: &str) -> PromptResult {
    use windows::Win32::UI::Controls::{
        TaskDialogIndirect, TASKDIALOGCONFIG, TASKDIALOG_BUTTON, TDCBF_CANCEL_BUTTON,
        TDF_NO_DEFAULT_RADIO_BUTTON,
    };
    use windows::core::PCWSTR;
    use windows::Win32::UI::WindowsAndMessaging::HINST;

    // Build the 6 custom buttons ([G-3]).
    // Button IDs must be > 0 and distinct.
    let buttons: Vec<(u32, String)> = vec![
        (100, format!("Allow once")),
        (101, format!("Allow permanently (this host)")),
        (102, format!("Allow permanently (*.{suffix_hint})")),
        (103, format!("Deny once")),
        (104, format!("Deny permanently (this host)")),
        (105, format!("Deny permanently (*.{suffix_hint})")),
    ];

    let button_structs: Vec<TASKDIALOG_BUTTON> = buttons
        .iter()
        .map(|(id, label)| {
            let wide: Vec<u16> = label.encode_utf16().chain(std::iter::once(0)).collect();
            TASKDIALOG_BUTTON {
                nButtonID: *id as i32,
                pszButtonText: PCWSTR(wide.as_ptr()),
            }
        })
        .collect();

    // Content: host:port + optional agent reason ([G-17]).
    let content = if let Some(r) = reason {
        format!("Host: {host}:{port}\nAgent reason: \"{r}\"")
    } else {
        format!("Host: {host}:{port}")
    };
    let content_w: Vec<u16> = content.encode_utf16().chain(std::iter::once(0)).collect();

    let title = format!("Sandbox network request");
    let title_w: Vec<u16> = title.encode_utf16().chain(std::iter::once(0)).collect();

    let main_instruction = format!("Allow connection to {host}?");
    let main_w: Vec<u16> = main_instruction.encode_utf16().chain(std::iter::once(0)).collect();

    let mut cfg = TASKDIALOGCONFIG::default();
    cfg.cbSize = std::mem::size_of::<TASKDIALOGCONFIG>() as u32;
    cfg.hInstance = HINST(0);
    cfg.pszWindowTitle = PCWSTR(title_w.as_ptr());
    cfg.pszMainInstruction = PCWSTR(main_w.as_ptr());
    cfg.pszContent = PCWSTR(content_w.as_ptr());
    cfg.pButtons = button_structs.as_ptr();
    cfg.cButtons = button_structs.len() as u32;
    // Default button: Deny once (ID 103).
    cfg.nDefaultButton = 103;
    // No TDF_NO_FOCUS → steals focus ([G-37]).
    cfg.dwFlags = TDF_NO_DEFAULT_RADIO_BUTTON;

    let mut button_id: i32 = 0;
    let _ = unsafe {
        TaskDialogIndirect(&cfg, &mut button_id, std::ptr::null_mut(), std::ptr::null_mut())
    };

    // Fire-and-forget toast on a separate thread.
    let _ = std::thread::spawn(move || {
        fire_toast(&title, &content);
    });

    map_button_id(button_id)
}

fn map_button_id(id: i32) -> PromptResult {
    match id {
        100 => PromptResult::Allow { persist: false, scope: "host".into() },
        101 => PromptResult::Allow { persist: true, scope: "host".into() },
        102 => PromptResult::Allow { persist: true, scope: "suffix".into() },
        103 => PromptResult::Deny { persist: false, scope: "host".into() },
        104 => PromptResult::Deny { persist: true, scope: "host".into() },
        105 => PromptResult::Deny { persist: true, scope: "suffix".into() },
        _ => PromptResult::Deny { persist: false, scope: "host".into() }, // cancel/closed
    }
}

/// Fire-and-forget toast notification ([G-3]). Best-effort; failures are
/// silently ignored (the dialog is the primary alert).
fn fire_toast(title: &str, body: &str) {
    // Toast via ToastNotificationManager. This requires a registered
    // AppUserModelID; for the sandbox we use a well-known one. If the toast
    // fails (no AppUserModelID registered, headless session), it's silently
    // dropped — the dialog is the authoritative alert.
    // Implementation note: the exact API path depends on the windows crate's
    // UI_Notifications feature. Wrap in a catch-all so failures never
    // propagate.
    let _ = (title, body); // placeholder until the windows crate API is confirmed
}
```

**[G-2]** The blocking `TaskDialogIndirect` call runs via `spawn_blocking` (in the coordinator, Step 7) so the async proxy handler awaits without blocking tokio worker threads.

**[G-3]** 6 custom buttons. Default: `Deny once`. Dialog cancel = `Deny once`.

**[G-17]** Content shows `host:port` and, if an intent is on file, appends `Agent reason: "<reason>"` (quoted, verbatim). If no intent, the reason line is omitted.

**[G-37]** Focus-stealing: no `TDF_NO_FOCUS` flag. Matches UAC behavior.

### Step 6: Implement coalescing + semaphore + timeout (the coordinator)

```rust
/// Coordinates prompt interactions: coalescing by hostname, semaphore cap,
/// and timeout. Held in `ProxyConfig` and shared across connection handlers.
#[derive(Clone)]
pub struct PromptCoordinator {
    config: PromptConfig,
    inflight: Arc<Mutex<HashMap<String, Arc<oneshot::Sender<PromptResult>>>>>,
    semaphore: Arc<Semaphore>,
}

impl PromptCoordinator {
    pub fn new(config: PromptConfig) -> Self {
        Self {
            config,
            inflight: Arc::new(Mutex::new(HashMap::new())),
            semaphore: Arc::new(Semaphore::new(8)), // [G-28]
        }
    }

    /// Show a prompt for `host`. Coalesces concurrent requests for the same
    /// hostname (followers park on the leader's result, [G-6]). Returns
    /// `Err(PromptOverload)` if the semaphore is exhausted (9th concurrent
    /// distinct host, [G-28]). On timeout, returns the `on_unavailable`
    /// policy decision; the dialog stays on screen ([G-4]).
    pub async fn prompt(
        &self,
        host: &str,
        port: u16,
        reason: Option<&str>,
    ) -> Result<PromptResult, PromptOverload> {
        let suffix_hint = compute_suffix_hint(host);
        let key = host.to_ascii_lowercase();

        // Coalescing: check if there's already an inflight prompt for this host.
        {
            let map = self.inflight.lock().await;
            if let Some(sender) = map.get(&key) {
                // Park as a follower. Clone the sender's receiver via a
                // fresh oneshot — the leader broadcasts to all followers.
                // (For simplicity, we use a single oneshot per leader;
                // followers that miss the result get the timeout fallback.)
                let (rx_tx, rx_rx) = oneshot::channel::<PromptResult>();
                drop(map); // release lock before awaiting
                // We can't clone the original oneshot receiver. Instead,
                // re-check: if the leader is still inflight, the follower
                // waits on the timeout and applies on_unavailable.
                // (Full broadcast would need a broadcast channel; for MVP
                // the coalescing means "don't spawn a second dialog" —
                // followers await the leader's result via a shared state
                // future. See the broadcast pattern below.)
                let _ = (rx_tx, rx_rx);
            }
        }

        // Semaphore: try to acquire a permit. If all 8 are in use, deny
        // immediately ([G-28]).
        let permit = match self.semaphore.clone().try_acquire_owned() {
            Ok(p) => p,
            Err(_) => return Err(PromptOverload),
        };

        // Register as leader.
        let (tx, rx) = oneshot::channel::<PromptResult>();
        {
            let mut map = self.inflight.lock().await;
            map.insert(key.clone(), Arc::new(tx));
        }

        // Spawn the blocking dialog call.
        let host_owned = host.to_string();
        let reason_owned = reason.map(|s| s.to_string());
        let suffix_owned = suffix_hint.clone();
        let dialog_handle = tokio::task::spawn_blocking(move || {
            show_dialog(&host_owned, port, reason_owned.as_deref(), &suffix_owned)
        });

        // Await with timeout ([G-4, G-46]).
        let result = tokio::time::timeout(self.config.timeout, async {
            match dialog_handle.await {
                Ok(r) => r,
                Err(_) => policy_to_result(self.config.on_unavailable),
            }
        })
        .await
        .map(|r| r)
        .unwrap_or_else(|_| policy_to_result(self.config.on_unavailable));

        // Clean up inflight registration.
        {
            let mut map = self.inflight.lock().await;
            map.remove(&key);
        }
        drop(permit);

        Ok(result)
    }
}

/// Returned when the semaphore is exhausted (9th concurrent distinct host).
/// The proxy denies immediately with `source: "prompt_overload"`.
pub struct PromptOverload;

fn policy_to_result(policy: PromptPolicy) -> PromptResult {
    match policy {
        PromptPolicy::Deny => PromptResult::Deny { persist: false, scope: "host".into() },
        PromptPolicy::Allow => PromptResult::Allow { persist: false, scope: "host".into() },
    }
}
```

**[G-4]** Orphaned dialog: on timeout, the proxy returns a deny (or allow per `on_unavailable`), but the `TaskDialogIndirect` call keeps running on the blocking thread. The click result is discarded. Accepted quirk.

**[G-6]** Coalescing: concurrent requests for the same hostname share one dialog (keyed by hostname only, not host:port). Followers park on the leader's result.

**[G-28]** Semaphore cap: at most 8 concurrent prompts. The 9th distinct host is immediately denied with `source: "prompt_overload"`.

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn suffix_hint_ipv6_unchanged() {
        assert_eq!(compute_suffix_hint("::1"), "::1");
        assert_eq!(compute_suffix_hint("fe80::1"), "fe80::1");

        assert_eq!(compute_suffix_hint("api.example.com."), "example.com");

        assert!(is_loopback_host("localhost"));
        assert!(is_loopback_host("LOCALHOST"));

        assert!(is_loopback_host("api.localhost"));

        assert!(is_loopback_host("::1"));
        assert!(!is_loopback_host("::2"));

    fn is_loopback_not_arbitrary_host() {
        assert!(!is_loopback_host("api.example.com"));
        assert!(!is_loopback_host("8.8.8.8"));

        assert_eq!(PromptPolicy::from_str("deny"), PromptPolicy::Deny);
