# Task: D-3.4 — Intent registry

> **ADR:** ADR-0001 §D-4 [G-7, G-8, G-16, G-25, G-26, G-57]
> **Phase:** 3 (D-3 + D-4, co-dependent)
> **Depends on:** none (pure in-memory module)
> **Blocks:** D-3.5 (prompt displays intent reason), D-3.6 (wire endpoints)

## Objective

Create `src/net/intent.rs` with an `IntentRegistry`: an in-memory, TTL-evicted store where the sandboxed agent POSTs "I want to reach host X because Y" *before* the network request. The prompt dialog (D-3.5) consumes the reason. The registry is eventually-consistent (in-memory map, lock-protected) — intent POST and CONNECT are independent requests; the agent cooperates by declaring first.

## Current state

No intent registry exists. The proxy has no concept of agent-declared intent.

### Step 2: Define the structs + registry

```rust
//! Agent-declared intent registry (ADR-0001 §D-4).
//!
//! The agent POSTs "I want to reach host X because Y" *before* the network
//! request. The prompt dialog (D-3.5) displays that reason. In-memory only,
//! TTL-evicted, lost on supervisor restart ([G-16]). All ops behind a
//! `tokio::sync::Mutex`.

use std::collections::HashMap;
use std::sync::Arc;
use std::time::{Duration, Instant};

use tokio::sync::Mutex;
use tokio::task::JoinHandle;

/// Max entries before oldest eviction ([G-16]).
const MAX_ENTRIES: usize = 500;
/// Max reason length; longer strings are truncated ([G-57]).
const MAX_REASON_LEN: usize = 500;

/// One intent entry.
#[derive(Debug, Clone)]
pub struct Entry {
    pub host: String,
    pub reason: String,
    pub ts: Instant,
    explain_more: bool,
}

/// The intent registry. Clone-able (wraps `Arc<Mutex<Inner>>`).
#[derive(Clone)]
pub struct IntentRegistry {
    inner: Arc<Mutex<Inner>>,
    sweeper: Arc<Mutex<Option<JoinHandle<()>>>>,
}

struct Inner {
    entries: HashMap<String, Entry>,
    ttl: Duration,
}

impl IntentRegistry {
    /// Create a new registry with `ttl`. Starts a background sweeper at
    /// TTL/2 that evicts expired entries ([G-16]).
    pub fn new(ttl: Duration) -> Self {
        let inner = Arc::new(Mutex::new(Inner {
            entries: HashMap::new(),
            ttl,
        }));
        let sweeper_ttl = ttl / 2;
        let sweeper_inner = inner.clone();
        let sweeper = tokio::spawn(async move {
            let mut interval = tokio::time::interval(sweeper_ttl);
            interval.tick().await; // skip immediate first tick
            loop {
                interval.tick().await;
                let now = Instant::now();
                let mut guard = sweeper_inner.lock().await;
                guard.entries.retain(|_, e| now.duration_since(e.ts) < guard.ttl);
            }
        });
        Self {
            inner,
            sweeper: Arc::new(Mutex::new(Some(sweeper))),
        }
    }

    /// Record an intent for `target`. `target` is normalized to a lowercase
    /// hostname (port stripped, path stripped, URL form → hostname,
    /// `host:port` → host) per [G-8]. `reason` is truncated to 500 chars
    /// ([G-57]). Overwrites any existing entry for the host.
    pub async fn record(&self, target: &str, reason: &str) {
        let host = normalize_target(target);
        let truncated_reason = if reason.len() > MAX_REASON_LEN {
            reason[..MAX_REASON_LEN].to_string()
        } else {
            reason.to_string()
        };
        let entry = Entry {
            host: host.clone(),
            reason: truncated_reason,
            ts: Instant::now(),
            explain_more: false,
        };
        let mut guard = self.inner.lock().await;
        // Evict oldest on overflow ([G-16]).
        if guard.entries.len() >= MAX_ENTRIES && !guard.entries.contains_key(&host) {
            if let Some(oldest_key) = guard.entries
                .iter()
                .min_by_key(|(_, e)| e.ts)
                .map(|(k, _)| k.clone())
            {
                guard.entries.remove(&oldest_key);
            }
        }
        guard.entries.insert(host, entry);
    }

    /// Look up the live intent for `host`. Returns `None` if missing or
    /// expired ([G-25]).
    pub async fn lookup_host(&self, host: &str) -> Option<Entry> {
        let h = normalize_target(host);
        let guard = self.inner.lock().await;
        let entry = guard.entries.get(&h)?;
        if guard.ttl > Duration::ZERO && entry.ts.elapsed() >= guard.ttl {
            return None;
        }
        Some(entry.clone())
    }

    /// Set the one-shot "explain more" flag for `host` ([G-26]).
    pub async fn mark_explain_more(&self, host: &str) {
        let h = normalize_target(host);
        let mut guard = self.inner.lock().await;
        if let Some(e) = guard.entries.get_mut(&h) {
            e.explain_more = true;
        } else {
            // Record a placeholder so the flag survives until consumed.
            guard.entries.insert(h.clone(), Entry {
                host: h,
                reason: String::new(),
                ts: Instant::now(),
                explain_more: true,
            });
        }
    }

    /// Consume the "explain more" flag (one-shot read + clear, [G-26]).
    pub async fn consume_explain_more(&self, host: &str) -> bool {
        let h = normalize_target(host);
        let mut guard = self.inner.lock().await;
        if let Some(e) = guard.entries.get_mut(&h) {
            let was = e.explain_more;
            e.explain_more = false;
            was
        } else {
            false
        }
    }

    /// Clear the "explain more" flag without reading.
    pub async fn clear_explain_more(&self, host: &str) {
        let h = normalize_target(host);
        let mut guard = self.inner.lock().await;
        if let Some(e) = guard.entries.get_mut(&h) {
            e.explain_more = false;
        }
    }

    /// Stop the background sweeper. After `close`, the registry still
    /// works but expired entries are no longer auto-evicted.
    pub async fn close(&self) {
        if let Some(handle) = self.sweeper.lock().await.take() {
            handle.abort();
        }
    }
}

/// Normalize `target` to a lowercase hostname ([G-8]). Accepts:
/// - URL form (`https://api.example.com/path` → `api.example.com`)
/// - `host:port` → `host`
/// - bare host → as-is, lowercased
/// - IPv4/IPv6 literal → as-is (lowercased)
pub fn normalize_target(target: &str) -> String {
    let t = target.trim();
    // URL form: scheme://host[:port]/path
    if let Some(after_scheme) = t.find("://") {
        let after = &t[after_scheme + 3..];
        let host_port = after.split('/').next().unwrap_or(after);
        return strip_port(host_port).to_ascii_lowercase();
    }
    // host:port (but not bare IPv6 like ::1)
    strip_port(t).to_ascii_lowercase()
}

/// Strip `:port` from `host:port`, unless it's a bare IPv6 literal
/// (`[::1]` or `::1`) with no port suffix.
fn strip_port(s: &str) -> &str {
    // Bracketed IPv6: [::1]:port or [::1]
    if s.starts_with('[') {
        if let Some(close) = s.find(']') {
            let inside = &s[1..close];
            return inside;
        }
    }
    // For non-IPv6, split on the last `:` only if there's exactly one colon
    // (host:port). IPv6 literals with multiple colons and no brackets are
    // treated as bare hosts.
    let colon_count = s.matches(':').count();
    if colon_count == 1 {
        if let Some(idx) = s.rfind(':') {
            return &s[..idx];
        }
    }
    s
}

#[cfg(test)]
mod tests {
    use super::*;
    use std::time::Duration;

    #[test]
    fn normalize_url_strips_scheme_path_port() {
        assert_eq!(normalize_target("https://api.example.com/v1/messages"), "api.example.com");
        assert_eq!(normalize_target("http://localhost:8080/path"), "localhost");
        assert_eq!(normalize_target("https://api.example.com:443/path"), "api.example.com");
    }

    #[test]
    fn normalize_host_port() {
        assert_eq!(normalize_target("api.example.com:443"), "api.example.com");
        assert_eq!(normalize_target("localhost:8080"), "localhost");
    }

    #[test]
    fn normalize_bare_host() {
        assert_eq!(normalize_target("API.Example.COM"), "api.example.com");
        assert_eq!(normalize_target("api.example.com"), "api.example.com");
    }

    #[test]
    fn normalize_ipv6_literal() {
        // Bracketed IPv6 with port.
        assert_eq!(normalize_target("[::1]:443"), "::1");
        // Bare IPv6 (no port, no brackets).
        assert_eq!(normalize_target("::1"), "::1");
        assert_eq!(normalize_target("fe80::1"), "fe80::1");
    }

    #[tokio::test]
    async fn record_and_lookup() {
        let reg = IntentRegistry::new(Duration::from_secs(60));
        reg.record("https://api.example.com/path", "fetching model list").await;
        let entry = reg.lookup_host("api.example.com").await.unwrap();
        assert_eq!(entry.host, "api.example.com");
        assert_eq!(entry.reason, "fetching model list");
        reg.close().await;
    }

    #[tokio::test]
    async fn lookup_missing_returns_none() {
        let reg = IntentRegistry::new(Duration::from_secs(60));
        assert!(reg.lookup_host("nope.example.com").await.is_none());
        reg.close().await;
    }

    #[tokio::test]
    async fn ttl_expiry() {
        let reg = IntentRegistry::new(Duration::from_millis(50));
        reg.record("api.example.com", "reason").await;
        assert!(reg.lookup_host("api.example.com").await.is_some());
        tokio::time::sleep(Duration::from_millis(100)).await;
        assert!(reg.lookup_host("api.example.com").await.is_none());
        reg.close().await;
    }

    #[tokio::test]
    async fn explain_more_one_shot() {
        let reg = IntentRegistry::new(Duration::from_secs(60));
        reg.record("api.example.com", "reason").await;
        reg.mark_explain_more("api.example.com").await;
        // First consume → true.
        assert!(reg.consume_explain_more("api.example.com").await);
        // Second consume → false (one-shot).
        assert!(!reg.consume_explain_more("api.example.com").await);
        reg.close().await;
    }

    #[tokio::test]
    async fn explain_more_without_existing_record() {
        let reg = IntentRegistry::new(Duration::from_secs(60));
        reg.mark_explain_more("api.example.com").await;
        assert!(reg.consume_explain_more("api.example.com").await);
        assert!(!reg.consume_explain_more("api.example.com").await);
        reg.close().await;
    }

    #[tokio::test]
    async fn clear_explain_more_without_consuming() {
        let reg = IntentRegistry::new(Duration::from_secs(60));
        reg.record("api.example.com", "reason").await;
        reg.mark_explain_more("api.example.com").await;
        reg.clear_explain_more("api.example.com").await;
        assert!(!reg.consume_explain_more("api.example.com").await);
        reg.close().await;
    }

    #[tokio::test]
    async fn overwrite_existing_entry() {
        let reg = IntentRegistry::new(Duration::from_secs(60));
        reg.record("api.example.com", "old reason").await;
        reg.record("api.example.com", "new reason").await;
        let entry = reg.lookup_host("api.example.com").await.unwrap();
        assert_eq!(entry.reason, "new reason");
        reg.close().await;
    }

    #[tokio::test]
    async fn reason_truncated_to_500() {
        let reg = IntentRegistry::new(Duration::from_secs(60));
        let long_reason = "x".repeat(600);
        reg.record("api.example.com", &long_reason).await;
        let entry = reg.lookup_host("api.example.com").await.unwrap();
        assert_eq!(entry.reason.len(), 500);
        reg.close().await;
    }

    #[tokio::test]
    async fn overflow_evicts_oldest() {
        let reg = IntentRegistry::new(Duration::from_secs(60));
        // Fill to MAX_ENTRIES.
        for i in 0..MAX_ENTRIES {
            reg.record(&format!("host{i}.example.com"), "reason").await;
        }
        assert!(reg.lookup_host("host0.example.com").await.is_some());
        // Add one more → evicts oldest (host0).
        reg.record("overflow.example.com", "reason").await;
        assert!(reg.lookup_host("host0.example.com").await.is_none(), "oldest should be evicted");
        assert!(reg.lookup_host("overflow.example.com").await.is_some());
        reg.close().await;
    }

    #[tokio::test]
    async fn lookup_normalizes_host() {
        let reg = IntentRegistry::new(Duration::from_secs(60));
        reg.record("https://API.Example.COM:443/path", "reason").await;
        // Lookup with various forms should all hit the same entry.
        assert!(reg.lookup_host("api.example.com").await.is_some());
        assert!(reg.lookup_host("API.Example.COM").await.is_some());
        reg.close().await;
    }
}
```

**[G-8]** Normalization: lowercased hostname, port stripped, path stripped, URL form → hostname. `host:port` → host.

**[G-16]** In-memory only, no disk persistence. TTL + sweeper at TTL/2. Max 500 entries; overflow evicts oldest.

**[G-25]** Intent POST and CONNECT are independent; the registry is eventually-consistent. `lookup_host` returns `None` if missing or expired.

**[G-26]** "Explain more" is a one-shot flag: `consume_explain_more` reads + clears in one atomic operation. No retry cap.

**[G-57]** Reasons >500 chars are truncated (not rejected). The endpoint contract is: POST → 204, GET → 200/404, explain → 204.
