# Task: D-3.1 — Profile + CLI fields for prompt configuration

> **ADR:** ADR-0001 §D-3 [G-46, G-47, G-48]
> **Phase:** 3 (D-3 + D-4, co-dependent)
> **Depends on:** D-0.1 (capability SID), D-0.3 (Proxy-Authorization)
> **Blocks:** D-3.2, D-3.5, D-3.6

## Objective

Add the profile + CLI surface for prompt configuration: `deny_domain`, `prompt_enabled`, `on_unavailable`, `prompt_timeout_secs`, `upstream_proxy`. These fields are parsed now (even though some — `upstream_proxy` — are only consumed in Phase 4) so that the profile schema is complete and backward-compatible. Thread them through `NetworkSlice`, `NetworkConfig::Allow`, and `resolve_network`. Add the `--no-prompt` and `--deny-domain` CLI flags.

## Current state

`src/profile.rs` lines 251–260 define `RawNetwork` with only `block_net`, `allow_domain`, `profile`. `NetworkSlice` (lines 153–158) carries only `block_net`, `allow_domain`, `profile_name`. `merge_profiles` (line 454) merges `block_net`, `allow_domain`, `profile`. `resolve_network_slice` (line 510) copies only those three fields. `to_expanded_json` (line 121) emits only `block` / `allow_domain` / `profile`.

`src/cli.rs` `Cmd::Run` (lines 17–60) has `--block-net`, `--allow-domain`, `--network-profile` — no `--no-prompt`, no `--deny-domain`.

`src/net/mod.rs` `NetworkConfig::Allow` (lines 21–25) carries `allow_domain`, `proxy_port`, `token` — no prompt-related fields. `resolve_network` (line 47) does not thread prompt config.

### Step 7: Update `resolve_network`

Update `resolve_network` (line 47) to accept the new fields and populate `NetworkConfig::Allow`. Add `cli_no_prompt: bool` and `cli_deny_domain: &[String]` parameters:

```rust
pub fn resolve_network(
    profile_net: &NetworkSlice,
    cli_block_net: bool,
    cli_allow_domain: &[String],
    cli_deny_domain: &[String],
    cli_no_prompt: bool,
    cli_network_profile: Option<&str>,
) -> NetworkConfig {
    // ... existing block logic unchanged ...

    let mut deny: Vec<String> = Vec::new();
    deny.extend(profile_net.deny_domain.iter().cloned());
    deny.extend(cli_deny_domain.iter().cloned());
    deny = dedupe(deny);

    let prompt_enabled = !cli_no_prompt
        && profile_net.prompt_enabled.unwrap_or(true); // [G-47] default-on

    let on_unavailable = profile_net.on_unavailable.clone()
        .unwrap_or_else(|| "deny".to_string());

    let prompt_timeout_secs = profile_net.prompt_timeout_secs.unwrap_or(60); // [G-46]

    if allow.is_empty() && deny.is_empty() {
        return NetworkConfig::Blocked;
    }
    // Allow-list mode: empty allow is Blocked only when prompt is off.
    // When prompt is on, an empty allow-list means "prompt for everything."
    if allow.is_empty() && !prompt_enabled {
        return NetworkConfig::Blocked;
    }

    NetworkConfig::Allow {
        allow_domain: allow,
        deny_domain: deny,
        prompt_enabled,
        on_unavailable,
        prompt_timeout_secs,
        upstream_proxy: profile_net.upstream_proxy.clone(),
        profile_name,
        proxy_port: None,
        token: None,
    }
}
```

**[G-47]** `prompt_enabled` defaults to `true` when network is active (i.e. `NetworkConfig::Allow`), unless the profile explicitly sets `promptEnabled: false` or the CLI passes `--no-prompt`.

**[G-48]** `on_unavailable` defaults to `"deny"`. Profile-only field (no CLI flag).

**[G-46]** `prompt_timeout_secs` defaults to `60`. Profile-only field (no CLI flag). A value of `0` means "instant deny" (handled by the prompt layer in D-3.5).

#[test]
fn raw_network_parses_camel_case_prompt_fields() {
    let raw = r#"{"meta":{"name":"x","schema_version":1},"network":{"allowDomain":["a.com"],"denyDomain":["*.evil.com"],"promptEnabled":false,"onUnavailable":"allow","promptTimeoutSecs":30,"upstreamProxy":"http://corp:8080"}}"#;
    let p: RawProfile = serde_json::from_str(raw).expect("parses");
    let n = p.network.unwrap();
    assert_eq!(n.deny_domain, vec!["*.evil.com"]);
    assert_eq!(n.prompt_enabled, Some(false));
    assert_eq!(n.on_unavailable.as_deref(), Some("allow"));
    assert_eq!(n.prompt_timeout_secs, Some(30));
    assert_eq!(n.upstream_proxy.as_deref(), Some("http://corp:8080"));
}
