# Task: D-3.6 — Wire prompt + intent + learned into proxy

> **ADR:** ADR-0001 §D-1, §D-3, §D-4 [G-22, G-24, G-29, G-33, G-35, G-38, G-44, G-52]
> **Phase:** 3 (D-3 + D-4, co-dependent)
> **Depends on:** D-3.1 (profile/CLI fields), D-3.2 (matcher expansion), D-3.3 (learned store), D-3.4 (intent registry), D-3.5 (prompt dialog), D-0.3 (Proxy-Authorization)
> **Blocks:** D-3.8 (integration tests), Phase 5 (D-1 finalization)

## Objective

Restructure `handle_conn` in `src/net/proxy.rs` to implement the full D-1 filter pipeline: hard-deny → learned-deny → deny_domain → allow → prompt/default. Add loopback-CONNECT refusal. After admission, perform DNS pinning + Happy Eyeballs dial. Route non-CONNECT `/sandbox/*` requests to the intent endpoints. Load `LearnedStore` + `IntentRegistry` + `PromptCoordinator` in `main.rs` and pass them into `ProxyConfig`.

## Current state

`src/net/proxy.rs` (279 lines) has a simple `handle_conn` that:
- Reads headers, checks the `X-Sandbox-Token` header (lines 197–205) — this was replaced by `Proxy-Authorization: Basic` in D-0.3.
- Parses host:port from CONNECT/forward (lines 208–222).
- Does a best-effort DNS resolve (lines 232–234) for the CIDR check.
- Calls `matcher::check(&host, &resolved, &allow)` (line 236) — the old 3-arg signature, before D-3.2's `deny_list`.
- On Allow, connects directly to `host:port` (line 241) — no DNS pinning, no Happy Eyeballs.
- On Deny, writes `403` (line 274) — no `X-Sandbox: denied` header, no body.

There is no intent endpoint routing, no learned-store integration, no prompt integration, no loopback-CONNECT refusal.

### Step 2: Restructure `handle_conn` — the full D-1 pipeline

Replace the body of `handle_conn` (lines 170–278) with the pipeline. The new flow:

```rust
async fn handle_conn(
    mut sock: tokio::net::TcpStream,
    token: Arc<String>,
    allow: Arc<Vec<String>>,
    deny: Arc<Vec<String>>,
    learned: Arc<tokio::sync::Mutex<crate::net::learned::LearnedStore>>,
    intent: crate::net::intent::IntentRegistry,
    prompt: crate::net::prompt::PromptCoordinator,
    writer: Arc<AuditWriter>,
) -> Result<()> {
    // Read up to 8 KiB of headers (unchanged).
    let mut buf = vec![0u8; 8192];
    let mut filled = 0;
    loop {
        if filled >= buf.len() { break; }
        let n = sock.read(&mut buf[filled..]).await.unwrap_or(0);
        if n == 0 { break; }
        filled += n;
        if buf[..filled].windows(4).any(|w| w == b"\r\n\r\n") { break; }
    }
    let head = std::str::from_utf8(&buf[..filled]).unwrap_or("");

    let first_line = head.lines().next().unwrap_or("");
    let mut parts = first_line.split_whitespace();
    let method = parts.next().unwrap_or("");
    let target = parts.next().unwrap_or("");

    // Proxy-Authorization: Basic check (from D-0.3).
    // ... (existing token check, updated to Proxy-Authorization) ...

    // Route non-CONNECT /sandbox/* requests to intent endpoints.
    if method != "CONNECT" && target.starts_with("/sandbox/") {
        return handle_intent_endpoint(&mut sock, &buf[..filled], method, target, &intent).await;
    }

    // Parse host:port (unchanged logic).
    let (host, port) = parse_host_port(method, target, head);

    if host.is_empty() {
        let _ = sock.write_all(b"HTTP/1.1 400 Bad Request\r\n\r\n").await;
        return Ok(());
    }

    // [G-44] Refuse loopback CONNECT.
    if method == "CONNECT" && crate::net::prompt::is_loopback_host(&host) {
        let _ = sock.write_all(b"HTTP/1.1 403 Forbidden\r\nX-Sandbox: denied\r\nContent-Length: 0\r\n\r\n").await;
        emit_connect_full(&writer, &host, port, "deny", "hard-deny", None, false);
        return Ok(());
    }

    // DNS resolve for pinning ([G-12]). Under upstream chaining (D-2/Phase 4),
    // skip this — but for now we always resolve.
    let resolved: Vec<IpAddr> = tokio::net::lookup_host(format!("{host}:0")).await
        .map(|it| it.map(|sa| sa.ip()).collect())
        .unwrap_or_default();

    // --- D-1 pipeline ([G-33]) ---

    // Step 1: hard-deny (hostname set + IP set).
    if crate::net::matcher::is_hard_denied_host(&host) {
        return deny_403(&mut sock, &writer, &host, port, "hard-deny", "denied_dns").await;
    }
    for ip in &resolved {
        if crate::net::matcher::is_hard_denied_ip(*ip) {
            return deny_403(&mut sock, &writer, &host, port, "hard-deny", "denied_cidr").await;
        }
    }

    // Step 2: learned permanent deny.
    let learned_guard = learned.lock().await;
    if let Some(decision) = learned_guard.lookup(&host) {
        if !decision.allow {
            drop(learned_guard);
            return deny_403(&mut sock, &writer, &host, port, "learned", "learned_deny").await;
        }
        // Learned allow — fall through to dial (step 4 allow path).
        drop(learned_guard);
        emit_connect_full(&writer, &host, port, "allow", "learned", Some(&decision.scope), true);
        return dial_and_splice(&mut sock, &host, port, &resolved, method, &buf[..filled]).await;
    }
    drop(learned_guard);

    // Step 3: deny_domain blocklist.
    if deny.iter().any(|e| crate::net::matcher::matches(&host, e)) {
        return deny_403(&mut sock, &writer, &host, port, "blocklist", "denied_domain").await;
    }

    // Step 4: allow_domain / learned-allow.
    if allow.iter().any(|e| crate::net::matcher::matches(&host, e)) {
        emit_connect_full(&writer, &host, port, "allow", "allowlist", None, false);
        return dial_and_splice(&mut sock, &host, port, &resolved, method, &buf[..filled]).await;
    }

    // Step 5: default — prompt or on_unavailable.
    // Look up intent reason for the dialog ([G-17]).
    let reason = intent.lookup_host(&host).await.map(|e| e.reason);

    match prompt.prompt(&host, port, reason.as_deref()).await {
        Ok(crate::net::prompt::PromptResult::Allow { persist, scope }) => {
            if persist {
                let mut guard = learned.lock().await;
                let _ = guard.record(&host, &scope, true).await;
            }
            emit_connect_full(&writer, &host, port, "allow", "prompt", Some(&scope), persist);
            dial_and_splice(&mut sock, &host, port, &resolved, method, &buf[..filled]).await
        }
        Ok(crate::net::prompt::PromptResult::Deny { persist, scope }) => {
            if persist {
                let mut guard = learned.lock().await;
                let _ = guard.record(&host, &scope, false).await;
            }
            deny_403(&mut sock, &writer, &host, port, "prompt", "user_deny").await
        }
        Ok(crate::net::prompt::PromptResult::NeedsIntent) => {
            // [G-52] 403 + X-Sandbox-Intent-Hint header.
            let body = format!("Connection to {host} denied. Re-declare intent with a reason.\r\n");
            let resp = format!(
                "HTTP/1.1 403 Forbidden\r\nX-Sandbox: denied\r\nX-Sandbox-Intent-Hint: explain-more\r\nContent-Length: {}\r\n\r\n{}",
                body.len(), body
            );
            let _ = sock.write_all(resp.as_bytes()).await;
            emit_connect_full(&writer, &host, port, "deny", "prompt", None, false);
            Ok(())
        }
        Err(_) => {
            // [G-28] prompt_overload.
            deny_403(&mut sock, &writer, &host, port, "prompt_overload", "semaphore_exhausted").await
        }
    }
}
```

### Step 3: Implement `dial_and_splice` with DNS pinning + Happy Eyeballs

```rust
/// Dial the resolved (pinned) IPs with Happy Eyeballs: race up to 8
/// concurrent connects, first success cancels the rest ([G-12]). Then
/// splice the tunnel (raw bytes, no TLS termination, [G-29]).
async fn dial_and_splice(
    sock: &mut tokio::net::TcpStream,
    host: &str,
    port: u16,
    pinned_ips: &[IpAddr],
    method: &str,
    head_buf: &[u8],
) -> Result<()> {
    let upstream = if pinned_ips.is_empty() {
        // DNS failed — try host:port directly (best-effort).
        tokio::net::TcpStream::connect(format!("{host}:{port}")).await
    } else {
        // Happy Eyeballs: race up to 8 concurrent dials.
        happy_eyeballs_dial(pinned_ips, port).await
    };

    let upstream = match upstream {
        Ok(s) => s,
        Err(e) => {
            let _ = sock.write_all(b"HTTP/1.1 502 Bad Gateway\r\nContent-Length: 0\r\n\r\n").await;
            eprintln!("[proxy] upstream connect to {host}:{port} failed: {e}");
            return Ok(());
        }
    };

    if method == "CONNECT" {
        let _ = sock.write_all(b"HTTP/1.1 200 Connection Established\r\n\r\n").await;
    } else {
        // For non-CONNECT, replay the original request bytes to upstream.
        let (mut ri, mut wi) = sock.into_split();
        let (mut ro, mut wo) = upstream.into_split();
        let _ = wo.write_all(head_buf).await;
        let c2u = tokio::io::copy(&mut ri, &mut wo);
        let u2c = tokio::io::copy(&mut ro, &mut wi);
        let _ = tokio::join!(c2u, u2c);
        return Ok(());
    }

    let (mut ri, mut wi) = sock.into_split();
    let (mut ro, mut wo) = upstream.into_split();
    let c2u = tokio::io::copy(&mut ri, &mut wo);
    let u2c = tokio::io::copy(&mut ro, &mut wi);
    let _ = tokio::join!(c2u, u2c);
    Ok(())
}

/// Happy Eyeballs (RFC 8305): race up to 8 concurrent `TcpStream::connect`
/// calls (one per pinned IP), first success cancels the rest, losers that
/// already connected are closed. [G-12]
async fn happy_eyeballs_dial(ips: &[IpAddr], port: u16) -> std::io::Result<tokio::net::TcpStream> {
    use futures_concurrency::prelude::*;
    // Each IP gets a connect future; race them all.
    let connects: Vec<_> = ips
        .iter()
        .take(8) // [G-12] maxParallelDials = 8
        .map(|ip| tokio::net::TcpStream::connect((*ip, port)))
        .collect();
    let (winner, _losers) = connects
        .into_group()
        .wait()
        .await;
    Ok(winner)
}
```

**Note:** `futures_concurrency` provides `wait()` for racing. If adding the crate is undesirable, a manual `tokio::select!` loop over semaphored tasks works (Phase 5, Task 5.2 refines this). For D-3.6, the key is that the pinned IPs (not the hostname) are dialed — that's the anti-rebinding property.

If `futures_concurrency` is not in `Cargo.toml`, use a simpler approach with `tokio::select!`:

```rust
async fn happy_eyeballs_dial(ips: &[IpAddr], port: u16) -> std::io::Result<tokio::net::TcpStream> {
    let mut tasks = Vec::new();
    for ip in ips.iter().take(8) {
        let addr = std::net::SocketAddr::new(*ip, port);
        let task = tokio::spawn(async move { tokio::net::TcpStream::connect(addr).await });
        tasks.push(task);
    }
    // First success wins; cancel the rest.
    let mut winner: Option<std::io::Result<tokio::net::TcpStream>> = None;
    for task in tasks {
        match task.await {
            Ok(Ok(s)) => { winner = Some(Ok(s)); break; }
            Ok(Err(_)) => continue,
            Err(_) => continue,
        }
    }
    winner.unwrap_or_else(|| Err(std::io::Error::new(std::io::ErrorKind::AddrNotAvailable, "all dials failed")))
}
```

**[G-12]** DNS pinning: resolve hostname once per request, dial the resolved IPs directly, never re-resolve. Happy Eyeballs handles dead-AAAA-record case.

**[G-22]** Under upstream chaining (D-2/Phase 4), skip local DNS and IP pinning — run hostname-only admission. Not implemented in this task (Phase 4).

**[G-29]** Raw tunnel, no TLS termination: the proxy splices bytes for CONNECT. TLS is end-to-end between child and real host.

### Step 4: Implement intent endpoint routing

```rust
/// Route non-CONNECT `/sandbox/*` requests to intent endpoints ([G-7, G-38]).
/// All endpoints require Proxy-Authorization (checked before this function).
async fn handle_intent_endpoint(
    sock: &mut tokio::net::TcpStream,
    head_buf: &[u8],
    method: &str,
    target: &str,
    intent: &crate::net::intent::IntentRegistry,
) -> Result<()> {
    // Parse body (after \r\n\r\n).
    let body = if let Some(idx) = head_buf.windows(4).position(|w| w == b"\r\n\r\n") {
        &head_buf[idx + 4..]
    } else {
        &[][..]
    };

    match (method, target) {
        ("POST", "/sandbox/intent") => {
            // Body: {"target":"...","reason":"..."} → 204 ([G-57]).
            let parsed: serde_json::Value = serde_json::from_slice(body).unwrap_or(serde_json::Value::Null);
            let target = parsed.get("target").and_then(|v| v.as_str()).unwrap_or("");
            let reason = parsed.get("reason").and_then(|v| v.as_str()).unwrap_or("");
            if target.is_empty() {
                let _ = sock.write_all(b"HTTP/1.1 400 Bad Request\r\nContent-Length: 0\r\n\r\n").await;
                return Ok(());
            }
            intent.record(target, reason).await;
            let _ = sock.write_all(b"HTTP/1.1 204 No Content\r\nContent-Length: 0\r\n\r\n").await;
        }
        ("GET", path) if path.starts_with("/sandbox/intent?") => {
            // Query: ?host=<host> → 200 with JSON or 404 ([G-57]).
            let query = &path["/sandbox/intent?".len()..];
            let host = query
                .strip_prefix("host=")
                .unwrap_or("")
                .split('&').next().unwrap_or("");
            let host = url_decode(host);
            match intent.lookup_host(&host).await {
                Some(entry) => {
                    let json = serde_json::json!({
                        "host": entry.host,
                        "reason": entry.reason,
                        "ts": format!("{:?}", entry.ts),
                    }).to_string();
                    let resp = format!("HTTP/1.1 200 OK\r\nContent-Type: application/json\r\nContent-Length: {}\r\n\r\n{}", json.len(), json);
                    let _ = sock.write_all(resp.as_bytes()).await;
                }
                None => {
                    let _ = sock.write_all(b"HTTP/1.1 404 Not Found\r\nContent-Length: 0\r\n\r\n").await;
                }
            }
        }
        ("POST", "/sandbox/intent/explain") => {
            // Body: {"host":"..."} → 204 ([G-57]).
            let parsed: serde_json::Value = serde_json::from_slice(body).unwrap_or(serde_json::Value::Null);
            let host = parsed.get("host").and_then(|v| v.as_str()).unwrap_or("");
            if host.is_empty() {
                let _ = sock.write_all(b"HTTP/1.1 400 Bad Request\r\nContent-Length: 0\r\n\r\n").await;
                return Ok(());
            }
            intent.mark_explain_more(host).await;
            let _ = sock.write_all(b"HTTP/1.1 204 No Content\r\nContent-Length: 0\r\n\r\n").await;
        }
        _ => {
            let _ = sock.write_all(b"HTTP/1.1 400 Bad Request\r\nContent-Length: 0\r\n\r\n").await;
        }
    }
    Ok(())
}

fn url_decode(s: &str) -> String {
    let mut out = String::new();
    let mut chars = s.chars().peekable();
    while let Some(c) = chars.next() {
        if c == '%' {
            let h1 = chars.next();
            let h2 = chars.next();
            if let (Some(a), Some(b)) = (h1, h2) {
                if let Ok(byte) = u8::from_str_radix(&format!("{a}{b}"), 16) {
                    out.push(byte as char);
                    continue;
                }
            }
        }
        if c == '+' { out.push(' '); } else { out.push(c); }
    }
    out
}
```

**[G-38]** `/sandbox/` prefix for all intent endpoints.

**[G-57]** POST → 204, GET → 200/404, explain → 204. Reasons >500 chars truncated (handled in `IntentRegistry::record`).

```rust
/// 403 + X-Sandbox: denied + body naming the host, policy reason, and
/// remediation paths ([G-52]).
async fn deny_403(
    sock: &mut tokio::net::TcpStream,
    writer: &AuditWriter,
    host: &str,
    port: u16,
    source: &str,
    reason: &str,
) -> Result<()> {
    let body = format!(
        "Connection to {host} denied.\nPolicy: {source} ({reason})\nRemediation: add to --allow-domain, --deny-domain, or use the interactive prompt.\n"
    );
    let resp = format!(
        "HTTP/1.1 403 Forbidden\r\nX-Sandbox: denied\r\nContent-Length: {}\r\n\r\n{}",
        body.len(), body
    );
    let _ = sock.write_all(resp.as_bytes()).await;
    emit_connect_full(writer, host, port, "deny", source, None, false);
    Ok(())
}
```

**[G-52]** Deny response: `403 Forbidden` with `X-Sandbox: denied` header + plain-text body naming the host, the policy reason, and remediation paths. For intent-related denials (`NeedsIntent`), add `X-Sandbox-Intent-Hint` header (handled in the pipeline above).
