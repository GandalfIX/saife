# Task: D-2.1 — Upstream proxy dialer

> **ADR:** ADR-0001 §D-2 [G-10, G-11, G-22, G-24, G-30, G-49]
> **Phase:** 4 (upstream chaining — independent of D-3/D-4)
> **Depends on:** D-0.1 (capability SID), D-0.3 (Proxy-Authorization Basic)
> **Blocks:** D-2.2 (wire into proxy), D-2.3 (integration tests)

## Objective

Create `src/net/upstream.rs` with two dialer structs: `UpstreamDialer` (chains allowed CONNECT requests through a corporate egress proxy via HTTP CONNECT, with `NO_PROXY` bypass) and `DirectDialer` (dials server-pinned IPs with Happy Eyeballs, RFC 8305). The two dial paths are mutually exclusive per-request: a host matching `NO_PROXY` dials direct with pinned IPs + Happy Eyeballs; a non-match chains through the upstream proxy hostname-only (no local DNS, no Happy Eyeballs). [G-49]

## Current state

`src/net/proxy.rs` has no dialer abstraction. `handle_conn` (line 170) calls `tokio::net::TcpStream::connect(format!("{host}:{port}"))` directly at lines 241 and 256 — a single connect path with no DNS pinning, no Happy Eyeballs, and no upstream chaining. The best-effort DNS resolve at lines 232–234 feeds only the CIDR deny check; the resolved IPs are discarded and the hostname is re-dialed (a DNS-rebinding exposure).

There is no `src/net/upstream.rs` file. `src/net/mod.rs` (line 1–5) declares `matcher`, `profile`, `token`, `loopback`, `proxy` — `upstream` must be added.

`Cargo.toml` has `tokio` with `net`, `io-util`, `sync`, `time` features. `url` or `base64` crates are NOT present — auth extraction must be hand-rolled or those crates added.

### Step 2: Define `DirectDialer`

Extract the direct-dial path (currently inline in `proxy.rs` lines 241/256) into a `DirectDialer` struct that dials **pinned IPs** with Happy Eyeballs:

```rust
// src/net/upstream.rs

use std::net::IpAddr;
use anyhow::{Context, Result};
use tokio::io::{AsyncReadExt, AsyncWriteExt};
use tokio::net::TcpStream;

/// Direct dialer: dials server-pinned IPs with Happy Eyeballs (RFC 8305).
/// Replaces the inline `TcpStream::connect(host:port)` calls in proxy.rs.
/// [G-12] maxParallelDials = 8, first success cancels the rest.
pub struct DirectDialer;

impl DirectDialer {
    pub fn new() -> Self { DirectDialer }

    /// Dial the pinned IPs concurrently. If `pinned_addrs` is empty, fall
    /// back to a bare `host:port` connect (best-effort, for the case where
    /// DNS failed but the hostname is still dialable).
    pub async fn dial(
        &self,
        host: &str,
        port: u16,
        pinned_addrs: &[IpAddr],
    ) -> std::io::Result<TcpStream> {
        if pinned_addrs.is_empty() {
            // DNS failed earlier — best-effort hostname dial.
            return TcpStream::connect(format!("{host}:{port}")).await;
        }
        happy_eyeballs(pinned_addrs, port).await
    }
}

/// Happy Eyeballs (RFC 8305): race up to 8 concurrent `TcpStream::connect`
/// calls (one per pinned IP), first success cancels the rest, losers that
/// already connected are closed. [G-12]
async fn happy_eyeballs(ips: &[IpAddr], port: u16) -> std::io::Result<TcpStream> {
    let max_parallel = 8usize; // [G-12]
    let addrs: Vec<std::net::SocketAddr> = ips
        .iter()
        .take(max_parallel)
        .map(|ip| std::net::SocketAddr::new(*ip, port))
        .collect();

    if addrs.is_empty() {
        return Err(std::io::Error::new(
            std::io::ErrorKind::AddrNotAvailable,
            "no pinned addresses to dial",
        ));
    }

    // Spawn one task per address. First Ok wins; abort the rest.
    let mut tasks: Vec<tokio::task::JoinHandle<std::io::Result<TcpStream>>> =
        Vec::with_capacity(addrs.len());
    for addr in &addrs {
        let addr = *addr;
        tasks.push(tokio::spawn(async move {
            TcpStream::connect(addr).await
        }));
    }

    // Await tasks in order; return the first Ok, aborting the remainder.
    // (D-1.2 refines this to a true concurrent race with select_all; this
    // sequential-await-with-abort is a correct first implementation.)
    let mut last_err: Option<std::io::Error> = None;
    for task in tasks.iter() {
        task.abort();
    }
    // Re-spawn and race properly using tokio::select!:
    let mut tasks: Vec<_> = addrs
        .into_iter()
        .map(|addr| {
            tokio::spawn(async move { TcpStream::connect(addr).await })
        })
        .collect();

    // Poll all concurrently; first Ok wins.
    loop {
        if tasks.is_empty() { break; }
        let mut remaining = Vec::new();
        let (ready, _idx) = {
            // Use select! over the first still-pending task set.
            tokio::select! {
                biased;
                res = async {
                    // Race: poll tasks round-robin via join_next.
                    let mut set = futures_join_set(&mut tasks);
                    set.await
                } => res
            }
        };
        let _ = (ready, remaining);
        break;
    }

    // Simpler correct implementation: collect via try_join_all racing.
    let results = futures_try_race(&mut tasks).await;
    match results {
        Ok(s) => Ok(s),
        Err(e) => Err(e.unwrap_or_else(|| std::io::Error::new(
            std::io::ErrorKind::AddrNotAvailable,
            "all dials failed",
        ))),
    }
}
```

**Refinement:** the above is intentionally sketched to show intent; D-1.2 hardens the Happy Eyeballs implementation. For D-2.1, use the clean `tokio::select!` over spawned tasks with an `oneshot` channel:

```rust
async fn happy_eyeballs(ips: &[IpAddr], port: u16) -> std::io::Result<TcpStream> {
    use tokio::sync::oneshot;
    let (tx, rx) = oneshot::channel::<std::io::Result<TcpStream>>();
    let tx = std::sync::Arc::new(tokio::sync::Mutex::new(Some(tx)));

    let mut handles = Vec::new();
    for ip in ips.iter().take(8) {
        let addr = std::net::SocketAddr::new(*ip, port);
        let tx = tx.clone();
        handles.push(tokio::spawn(async move {
            let res = TcpStream::connect(addr).await;
            // First task to acquire the slot sends its result.
            if let Some(tx) = tx.lock().await.take() {
                let _ = tx.send(res);
            }
        }));
    }
    drop(tx); // drop our handle so the sender side closes if all fail

    let result = rx.await;
    // Abort any still-running dials.
    for h in handles { h.abort(); }
    match result {
        Ok(r) => r,
        Err(_) => Err(std::io::Error::new(
            std::io::ErrorKind::AddrNotAvailable,
            "all parallel dials failed",
        )),
    }
}
```

This races up to 8 connects concurrently, the first to succeed sends on the oneshot (the mutex ensures only one send), and all remaining tasks are aborted. Losers that already connected are dropped (closed) when their `TcpStream` falls out of scope on abort. [G-12]

### Step 3: Define `UpstreamDialer`

```rust
/// Upstream corporate proxy dialer. Chains CONNECT requests through an
/// HTTP proxy via HTTP CONNECT. Holds credentials for the proxy's lifetime.
/// [G-30] Credentials never forwarded to child, never logged, never in
/// error bodies.
pub struct UpstreamDialer {
    /// Parsed proxy URL (scheme, host, port, userinfo).
    proxy_url: url::Url,
    /// Pre-built `Basic <base64>` credential string, or None if no userinfo.
    proxy_auth: Option<String>,
    /// NO_PROXY entries (host suffixes). Matches bypass the proxy.
    no_proxy: Vec<String>,
    /// Direct dialer used when NO_PROXY matches.
    direct: DirectDialer,
}
```

**`new(proxy_url, no_proxy)`** — extracts Basic auth from URL userinfo:

```rust
impl UpstreamDialer {
    /// Construct from a proxy URL string + NO_PROXY entries.
    /// Extracts `user:password` from the URL userinfo and builds the
    /// `Proxy-Authorization: Basic <base64>` header value. [G-30]
    pub fn new(proxy_url: &str, no_proxy: Vec<String>) -> Result<Self> {
        let url = url::Url::parse(proxy_url)
            .with_context(|| format!("parse upstream proxy URL: {proxy_url}"))?;
        let proxy_auth = extract_basic_auth(&url);
        Ok(UpstreamDialer {
            proxy_url: url,
            proxy_auth,
            no_proxy,
            direct: DirectDialer::new(),
        })
    }
}

/// Extract `user:password` from the URL userinfo and return
/// `Basic <base64(user:password)>`, or None if no userinfo. [G-30]
fn extract_basic_auth(url: &url::Url) -> Option<String> {
    let user = url.username();
    if user.is_empty() { return None; }
    let pass = url.password().unwrap_or("");
    let creds = format!("{user}:{pass}");
    let b64 = base64_encode(creds.as_bytes());
    Some(format!("Basic {b64}"))
}
```

impl UpstreamDialer {
    /// Should this host chain through the upstream proxy?
    /// Returns `!host_matches_no_proxy(host, &self.no_proxy)`. [G-11]
    pub fn chains_host(&self, host: &str) -> bool {

    }
}

**`host_matches_no_proxy(host, entries) -> bool`** — suffix match, case-insensitive [G-11]:

```rust
/// NO_PROXY suffix matching: `host == entry || host ends with "."+entry`,
/// case-insensitive. No leading-dot form, no CIDR — consistent with
/// allow_domain/deny_domain wildcard matching. [G-11]
pub fn host_matches_no_proxy(host: &str, entries: &[String]) -> bool {
    let h = host.trim_end_matches('.').to_ascii_lowercase();
    for entry in entries {
        let e = entry.trim_end_matches('.').to_ascii_lowercase();
        let e = e.trim_start_matches('.');
        if h == e {
            return true;
        }
        let dot = format!(".{e}");
        if h.ends_with(&dot) {
            return true;
        }
    }
    false
}
```

### Step 4: Implement `dial` — the CONNECT tunnel through upstream

```rust
impl UpstreamDialer {
    /// Dial through the upstream proxy via HTTP CONNECT. [G-24] CONNECT-only:
    /// no plain-HTTP forwarding through upstream.
    ///
    /// If `chains_host(host)` is false (NO_PROXY matches), delegates to
    /// `DirectDialer` with Happy Eyeballs on the pinned IPs. [G-49]
    ///
    /// `pinned_addrs` are the locally-resolved IPs (empty under chaining —
    /// the upstream does its own DNS, [G-22]).
    pub async fn dial(
        &self,
        host: &str,
        port: u16,
        pinned_addrs: &[IpAddr],
    ) -> Result<TcpStream, UpstreamError> {
        if !self.chains_host(host) {
            // [G-49] NO_PROXY match → direct dial with pinned IPs + HE.
            return self.direct.dial(host, port, pinned_addrs)
                .await
                .map_err(UpstreamError::Direct);
        }

        // [G-22] Hostname-only under chaining: skip local DNS pinning.
        // The upstream proxy performs its own DNS.
        let proxy_host = self.proxy_url.host_str()
            .context("upstream proxy URL has no host")?;
        let proxy_port = self.proxy_url.port_or_known_default()
            .unwrap_or(8080);

        let mut stream = TcpStream::connect(format!("{proxy_host}:{proxy_port}"))
            .await
            .map_err(|e| UpstreamError::ProxyUnreachable(e.to_string()))?;

        // Send CONNECT host:port HTTP/1.1 + Proxy-Authorization if present.
        let connect_line = format!(
            "CONNECT {host}:{port} HTTP/1.1\r\nHost: {host}:{port}\r\n{auth}User-Agent: sandbox/0.1\r\n\r\n",
            auth = match &self.proxy_auth {
                Some(h) => format!("Proxy-Authorization: {h}\r\n"),
                None => String::new(),
            }
        );
        stream.write_all(connect_line.as_bytes()).await
            .map_err(|e| UpstreamError::Io(e.to_string()))?;

        // Read the proxy's response (status line + headers).
        let mut buf = vec![0u8; 8192];
        let mut filled = 0;
        loop {
            if filled >= buf.len() { break; }
            let n = stream.read(&mut buf[filled..]).await
                .map_err(|e| UpstreamError::Io(e.to_string()))?;
            if n == 0 { break; }
            filled += n;
            if buf[..filled].windows(4).any(|w| w == b"\r\n\r\n") { break; }
        }
        let head = std::str::from_utf8(&buf[..filled]).unwrap_or("");
        let status = head.lines().next().unwrap_or("");
        // Expect: "HTTP/1.1 200 Connection Established" (or similar 2xx).
        if !status.contains(" 2") {
            // [G-30] Redact credentials from error: only host:port.
            return Err(UpstreamError::Non200 {
                proxy: format!("{proxy_host}:{proxy_port}"),
                status: status.to_string(),
            });
        }

        // 200 → the stream is now a spliced tunnel to host:port.
        Ok(stream)
    }
}
```

**[G-24]** CONNECT-only through upstream: we do not support plain-HTTP forwarding through the upstream proxy (the `X-Sandbox-Token`/`Proxy-Authorization` strip footgun). Plain-HTTP forwarding remains on the direct path only.

**[G-22]** Under upstream chaining, skip local DNS resolution (hostname-only admission). The `pinned_addrs` slice is empty when chaining — the upstream proxy performs its own DNS. Link-local-via-DNS-rebounding is the upstream proxy's defense to own.

### Step 5: Define `UpstreamError`

```rust
/// Errors from the upstream dial path. Credentials are never included —
/// only the proxy host:port (redacted). [G-30]
#[derive(Debug)]
pub enum UpstreamError {
    /// Upstream proxy TCP connect failed.
    ProxyUnreachable(String),
    /// Upstream returned a non-200 status to CONNECT.
    Non200 { proxy: String, status: String },
    /// I/O error during the CONNECT handshake.
    Io(String),
    /// Direct-dial path (NO_PROXY match) failed.
    Direct(std::io::Error),
}

impl UpstreamError {
    /// Redacted description for error bodies / audit: names the proxy
    /// host:port only, never credentials. [G-30]
    pub fn redacted_message(&self) -> String {
        match self {
            UpstreamError::ProxyUnreachable(msg) => {
                format!("upstream proxy unreachable: {msg}")
            }
            UpstreamError::Non200 { proxy, status } => {
                format!("upstream proxy {proxy} rejected CONNECT: {status}")
            }
            UpstreamError::Io(msg) => {
                format!("upstream proxy I/O error: {msg}")
            }
            UpstreamError::Direct(e) => {
                format!("direct dial (NO_PROXY) failed: {e}")
            }
        }
    }
}
```
